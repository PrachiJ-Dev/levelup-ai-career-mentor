# LevelUp AI Career Mentor – Comprehensive Technical Documentation

LevelUp is an end-to-end, high-performance AI ecosystem designed to solve the "Career Stagnation" problem. It transforms raw, unstructured professional data into a predictive, actionable roadmap using **Transformers (DistilBERT)**, **Recurrent Neural Networks (LSTM)**, and **Large Language Models (LLMs)**.

---

## 1. System Architecture & High-Level Workflow

LevelUp follows a modern **Decoupled Architecture** with a high-speed Python backend and a reactive TypeScript frontend.

### **The Data Lifecycle:**
1.  **Ingestion:** PDF Resume → `pdfminer.six` → Cleaned Tokenized Text.
2.  **NER Analysis:** Text → **DistilBERT** → Structured Entities (Skills, Roles, Experience).
3.  **Benchmarking:** Structured Entities → **Skill Taxonomy Engine** → Match Score & Gap Detection.
4.  **Sequencing:** Career History → **CareerLSTM** → Predictive Trajectory.
5.  **Remediation:** Skill Gaps → **CNN-Roadmap** → Phase-based Learning Path.
6.  **Validation:** AI Interviewer → **Groq LLM** → Real-time Technical Evaluation.

## 2. Deep Learning Pipelines: Under the Hood

### **A. Resume Intelligence (Transformer-based NER)**
*   **Model:** `distilbert-base-uncased` fine-tuned for professional entity recognition.
*   **Technique:** **Token Classification** with a custom IOB (Inside-Outside-Beginning) tagging scheme.
*   **Why DistilBERT?** It offers 95% of BERT's performance with 40% less parameter overhead, allowing for sub-300ms inference on a standard CPU.
*   **Mathematical Concept:** **Multi-Head Self-Attention**. The model calculates a "weight" for every word in the resume relative to every other word, allowing it to distinguish between "Java" (Programming Language) and "Java" (Island/Context) based on surrounding text.

### **B. Career Trajectory (Sequential LSTM)**
*   **Model:** **LSTM (Long Short-Term Memory)** with 2 hidden layers (128 units each).
*   **Input:** Career history encoded as a sequence of tensors $[Step_1, Step_2, ..., Step_n]$.
*   **Mechanism:** The LSTM uses "Forget Gates" to discard irrelevant historical data and "Input Gates" to store critical career pivots.
*   **Output:** A Softmax layer provides a probability distribution over the next probable roles.
*   **Integration:** If no history exists, the system uses **Zero-Shot Extraction** from the latest resume to bootstrap the model.

### **C. Interview Intelligence (LLM Orchestration)**
*   **Engine:** **Llama-3-70B** via the **Groq LPUs** (Language Processing Units).
*   **Prompt Engineering:** Uses "Chain of Thought" prompting to generate questions that are technically rigorous and tailored specifically to the user's detected skill gaps.
*   **Evaluation:** The system performs a **Semantic Similarity** check between the user's response and an "ideal" latent response generated by the model.

## 3. Data Architecture & Persistence

### **MongoDB Atlas (Cloud-Native Storage)**
We utilize a schema-less yet highly structured collection strategy:
*   **`users`**: Auth data + target career goals.
*   **`resumes`**: Stored binary paths + `extracted_text` + NER metadata.
*   **`skill_gaps`**: Point-in-time snapshots of the distance between user skills and role requirements.
*   **`career_history`**: Time-stamped career sequences for LSTM retraining and inference.
*   **`interviews`**: Question/Answer logs with performance metrics.

---

## 4. API Layer & Security

### **FastAPI Implementation:**
*   **Asynchronous I/O:** Every route is non-blocking, allowing the server to handle multiple ML inference requests simultaneously.
*   **JWT Security:** Uses **HS256** asymmetric encryption for session management. Tokens are generated upon login/registration and validated via a Bearer middleware.
*   **CORS Protection:** Strict origin filtering (allowing only verified frontend domains).

### **Core Endpoints:**
*   `POST /api/resume/upload`: Triggers the full NLP analysis pipeline.
*   `POST /api/career/predict`: Runs the LSTM sequence prediction.
*   `POST /api/interview/questions`: Dynamically generates AI questions.
*   `GET /api/auth/me/dashboard`: Aggregates cross-collection data for real-time stats.

## 5. Frontend & UI/UX Design Logic

### **The "Premium Dark" Aesthetic:**
*   **Tech Stack:** Next.js 14, Tailwind CSS, Framer Motion.
*   **Glassmorphism:** Use of `backdrop-blur` and `bg-white/5` to create a depth-filled, modern interface.
*   **Clean Slate Design:** We explicitly removed all placeholder data. Components are programmed to show "Action Links" (e.g., "Analyze Resume") instead of "Dummy Numbers." This ensures that when a user sees a number, it is 100% database-verified.

### **Responsive Animations:**
*   **CountUp:** Numbers animate from 0 to target values using Framer Motion's `useMotionValue`.
*   **Layout Transitions:** Smooth page fades and staggered entry for list items to reduce perceived latency.

## 6. Deployment & Scalability

### **Containerization (Docker):**
*   **Multi-Stage Builds:** Minimizes image size for faster deployment.
*   **Service Orchestration:** `docker-compose` manages the Backend, Frontend, and MongoDB instances as a unified network.

### **Environment Management:**
*   **`.env` driven configuration**: Allows switching between `DEMO_MODE` (static responses) and `PROD_MODE` (live ML inference) without code changes.
